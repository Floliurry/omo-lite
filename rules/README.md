# rules

主代理的常驻规则。基础指令说明所有代理共用的做法，这里只放主代理才需要的部分。

## 文件

| 文件 | 内容 |
| --- | --- |
| `lead.md` | 主代理规则，分三节：动手前先找方向并把可选方向交给用户选；哪些工作交给子代理、哪些自己做，以及怎么给子代理交代任务；什么时候用 `ultrawork`、`project-plan`、`ulw-plan` 等工作流 |

## 怎么注入

`lead.md` 不经过 `config.toml`，而是由 [`hooks/resident-rule.mjs`](../hooks/README.md) 注入：

- 会话开始或被清空时，钩子读出 `lead.md`，把正文里的 `{{model}}` 换成当前会话的模型名，作为附加上下文注入；
- 恢复的会话已经带着规则，不再注入；
- 上下文压缩之后，历史只以加密形式保留，钩子无法确认规则还在，所以只注入一行指向 `lead.md` 的提示，由主代理自己去读。

子代理不会收到这条规则；它们的指令来自基础指令和各自的[代理角色](../agents/README.md)。

## 修改

钩子注入前会去掉开头的 frontmatter，只注入正文。改完重新安装，新会话开始时生效。
